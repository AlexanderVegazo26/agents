# Motion graphics reference — Analytics, CTAs, variants, end cards, thumbnails, loops

Part of the `motion-graphics` skill. Section numbers match the skill's
index in SKILL.md.


# 69. Analytics and Iteration

When the video is intended for performance marketing or social media, identify measurable objectives.

Potential metrics:
- first-second retention,
- three-second retention,
- average watch time,
- completion rate,
- 25/50/75/100% view rate,
- CTA click-through rate,
- conversion rate,
- engagement,
- shares,
- saves.

Do not assume a metric is universally meaningful.

Define the hypothesis behind each variant.

# 70. CTA Tracking

When applicable:
- use UTM parameters,
- track campaign IDs,
- maintain unique links,
- maintain variant IDs,
- preserve attribution.

Example:

``` text
campaign=launch
creative=motion_01
variant=A
language=en
platform=instagram
```

# 71. A/B Variants

Change one meaningful variable at a time where possible.

Examples:
- Hook
- First frame
- CTA
- Music
- VO
- Headline
- Product demonstration order
- End card

Record:

``` text
experiment_id
hypothesis
variant
change
metric
result
decision
```

Do not claim causation from weak or uncontrolled data.

------------------------------------------------------------------------

# 72. End Card Localization

Create end-card variants for:
- Language
- Region
- CTA
- URL
- Legal disclaimer
- Product availability

Keep the animation structure reusable.

------------------------------------------------------------------------

# 73. Thumbnail Generation

Create thumbnails that:
- communicate the topic immediately,
- remain readable at small sizes,
- use strong contrast,
- preserve brand identity,
- avoid accidental frame selections.

Extract candidate frames and evaluate them separately.

------------------------------------------------------------------------

# 74. Looping Videos

For loopable motion:

1.  Define loop point.
2.  Match first and final visual state.
3.  Match motion velocity where appropriate.
4.  Match audio or create an intentional audio-less loop.
5.  Validate the loop for visible discontinuities.

Do not simply crossfade the beginning and end unless stylistically appropriate.
